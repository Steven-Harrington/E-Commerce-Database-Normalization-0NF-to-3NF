# SQL Database Normalization: 0NF to 3NF

**Technologies:** MySQL | SQL | Relational Database Design | Data Cleaning

## Project Overview

This project demonstrates the process of transforming an unnormalized dataset (0NF) into a structured relational database following Third Normal Form (3NF).

The goal is to improve database organization, reduce data redundancy, and support data integrity through SQL-based data cleaning and normalization techniques.

## Project Objectives

- Examine the original dataset to identify missing, inconsistent, and duplicate records.
- Clean and standardize data using SQL.
- Apply database normalization principles from 0NF through 3NF.
- Design relational tables using primary and foreign keys.
- Establish relationships between entities to reduce redundant data.

## Normalization Process

### 1. Unnormalized Form (0NF)

Analyze the original dataset and identify potential issues, including repeated information, inconsistent formatting, and missing values.

### 2. First Normal Form (1NF)

Organize the data into a relational structure with atomic column values and identifiable records.

### 3. Second Normal Form (2NF)

Identify and eliminate partial dependencies by separating attributes into appropriate relational tables.

### 4. Third Normal Form (3NF)

Eliminate transitive dependencies by separating attributes that depend on other non-key attributes.

## SQL Techniques Demonstrated

- Data validation and quality checks
- Conditional logic using `CASE` statements
- Data cleaning and standardization
- Table creation and schema design
- Primary and foreign key relationships
- Relational database normalization
